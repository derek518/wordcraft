# 词库数据来源

## ECDICT

- 仓库：https://github.com/skywind3000/ECDICT
- 许可：MIT
- 取用文件：`ecdict.csv`（约 63MB，77 万词条）
- 取用日期：2026-08-06

### 用到的字段

| 字段 | 用途 |
|---|---|
| `word` | 词形 |
| `phonetic` | 音标（原始不含斜杠，导出时补 `/ /`） |
| `translation` | 中文释义，含词性前缀 |
| `exchange` | 词形变化，用于推断词性（见下） |
| `tag` | 考纲标签，筛 `gk`（高考）/ `zk`（中考） |
| `bnc` | 英国国家语料库词频排名 |
| `frq` | 当代语料库词频排名 |

`pos` 字段在考纲词中 **100% 为空**，未使用。

### 获取方式

`raw.githubusercontent.com` 直连约 0.1 MB/分钟（63MB 需 10 小时），
jsDelivr 对该文件无响应。**改用 git 协议**，4 分钟完成：

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/skywind3000/ECDICT.git
cd ECDICT && git sparse-checkout disable   # sparse set 未触发拉取，disable 才落盘
```

原始 CSV 不入库（63MB），仅提交清洗后的 `words.json`。

## 词性推断依据

ECDICT 的 `translation` 按行列出多个词性，但**行序不代表常用度**——
`statue` 把 `vt. 以雕像装饰` 排在 `n. 雕像` 之前。

改用 `exchange` 字段的形态学证据约束候选词性：

| 变化标记 | 含义 | 可推出的词性 |
|---|---|---|
| `d` `p` `i` `3` | 过去式、过去分词、现在分词、三单 | 动词 |
| `s` | 复数 | 名词 |
| `r` `t` | 比较级、最高级 | 形容词 / 副词 |

在候选词性内取释义中出现的第一个；无候选时退回行序。

### 已知局限

| 情况 | 数量 | 占比 |
|---|---|---|
| 有形态学证据且命中 | 2,886 | 78.1% |
| `exchange` 为空 | 708 | 19.2% |
| 有证据但未命中 | 99 | 2.7% |

`exchange` 为空的多是本就没有词形变化的词（形容词 `abrupt`、介词 `about`、
不可数名词 `advice`），ECDICT 对这类词通常只列一个词性，行序无选择余地。

真正需要人工核对的是「无形态学证据 **且** 多词性」的 **178 词**，且其中大部分是
`about`(prep./adv.)、`all`(adj./adv./pron./n.) 这类**本就多词性的功能词**，
标注任一均不算错。题型为「词 → 释义」，`pos` 仅作展示，不参与判定。

## 词频档位

`frequency_band` 取 `bnc` 与 `frq` 中较高频的那个排名（即较小值）分档：

| band | 排名区间 |
|---|---|
| 1 | ≤ 1,000 |
| 2 | ≤ 3,000 |
| 3 | ≤ 6,000 |
| 4 | ≤ 12,000 |
| 5 | 其余（含两库均未收录） |

两个语料库各有盲区——BNC 偏英式书面语，当代语料库偏美式口语——取较高频者
更接近「学生实际会遇到」的频率。**无手填值**，满足契约 §8 的可追溯要求。
